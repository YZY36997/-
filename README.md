# 灵墨小说工坊

AI智能小说创作桌面应用

## 功能特性

- 项目化大纲分类与素材隔离体系
- AI创作页与素材库全链路打通
- 素材库 / AI生成器 / 自定义素材 三模块融合
- AI生成器精细化分类（20+细分生成器）
- 残缺大纲导入、补全与合成系统
- 爆文模板联网动态更新系统

## 技术栈

- 前端：Vue3 + Vite + Element Plus
- 后端：Express + Node.js
- 桌面：Electron 28
- 存储：本地JSON文件

## 快速开始

### 开发模式

```bash
npm run dev
```

### 生产构建

```bash
npm run build
```

### Electron 打包

```bash
npm run build:electron
```

## 使用说明

1. 首次使用请在"设置"中配置AI API密钥
2. 创建项目开始创作
3. 在素材库中管理你的创作素材
4. 使用AI生成器辅助创作
