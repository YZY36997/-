# 灵墨小说工坊 v3.5 产品需求文档 (PRD)

## 1. 产品概述

### 产品名称
**灵墨小说工坊** - AI智能小说创作桌面应用

### 核心定位
面向网文作者的AI辅助创作工具，提供从大纲设计、素材管理到正文生成的全流程支持。

### 目标用户
- 网文小说作者（玄幻、仙侠、都市、古言等题材）
- 有创作需求的自媒体人
- 想要尝试AI辅助写作的新人作者

### 核心价值
- **项目化隔离**：多部小说素材互不干扰
- **全链路打通**：素材库 → AI生成器 → 创作页无缝衔接
- **本地优先**：纯本地JSON存储，保护创作隐私
- **离线可用**：核心功能断网可正常使用

## 3. 功能模块

### 模块1：项目化大纲分类与素材隔离体系

#### 功能点
1. **导入大纲自动建项**
   - 每次导入大纲自动创建独立小说项目
   - 重复导入提示"覆盖更新"或"新建项目"

2. **两级素材体系**
   - 全局公共素材库：古代常识、民俗神话等通用素材，所有项目可调用
   - 项目私有素材库：每个项目独立的人设、世界观、场景、设定

3. **智能拆分归档**
   - 导入大纲后自动识别并拆分：世界观、人物、势力、章节、场景
   - 自动归档到对应项目的私有素材库

4. **前端导航改造**
   - 左侧新增"我的项目"树形导航
   - 点击项目切换查看对应私有素材、大纲、章节

#### 数据结构改造
- 新增 `projects.json` 项目表
- 所有素材新增 `project_id` 字段
- 全局公共素材 `project_id = null`

#### 验收标准
- 连续导入2份不同大纲，生成2个独立项目，私有素材互不干扰
- 全局素材在所有项目内均可查看、调用
- 原有历史素材、配置全部正常保留

---

### 模块2：AI创作页与素材库全链路打通

#### 功能点
1. **右侧常驻素材抽屉**
   - 可折叠素材面板
   - 支持"全局素材/当前项目素材"切换
   - 支持关键词搜索、分类筛选

2. **两种素材调用方式**
   - 一键插入正文：素材内容直接插入光标位置
   - 一键注入提示词：素材内容追加到"创作提示/上下文"输入框

3. **自动联动生成**
   - 新增"素材联动生成"开关
   - 开启后AI生成章节时，自动读取项目核心人设、世界观素材
   - 素材内容拼接到系统提示词，保证设定一致

4. **生成结果回存素材**
   - AI生成的人物、功法、场景内容
   - 支持右键"保存为项目素材"
   - 选择分类后直接归档到当前项目私有素材库

#### 验收标准
- 创作页内完成素材搜索、调用、保存全流程，无需跳转页面
- 开启联动后，生成内容自动贴合项目人设与世界观

---

### 模块3：素材库 / AI生成器 / 自定义素材 三模块融合重构

#### 功能点
1. **页面合并**
   - 将原"素材库与AI生成器"、"自定义素材库"合并为统一的"素材与生成中心"单页

2. **统一导航结构**
   - 左侧分类导航：公共素材库、项目素材库、AI生成器、爆文模板
   - 中间内容列表区
   - 右侧详情/编辑/生成面板

3. **双向联动能力**
   - 查看任意素材时，右上角可"用该素材调用生成器"
   - AI生成器产出结果后，可一键"保存为公共素材"或"保存到当前项目素材"
   - 自定义素材支持"套用生成器模板优化"

4. **删除投稿攻略**
   - 移除投稿攻略模块全部入口与代码

#### 验收标准
- 一个页面完成素材查阅、AI生成、自定义编辑全部操作
- 无投稿攻略相关入口与残留代码
- 操作流程比原分页面模式减少至少3次跳转

---

### 模块4：AI生成器精细化分类与自定义生成器

#### 功能点

**1. 生成器五级细分（20+细分生成器）**

| 大类 | 细分生成器 |
|------|-----------|
| 世界观设定类 | 故事主线、势力宗门、功法体系、世界规则、地理地图 |
| 人物角色类 | 主角设定、反派设计、配角群像、人物关系、角色成长线 |
| 剧情桥段类 | 剧情反转、高潮场景、打斗场面、情感互动、过渡衔接 |
| 文案包装类 | 黄金开头、书名生成、简介文案、章节标题、对话润色 |
| 辅助工具类 | 灵感火花、残缺大纲补全、多大纲合成、正文扩写/缩写 |

**2. 自定义生成器**
- 支持用户保存自己的Prompt模板
- 支持设置分类、参数、默认提示词
- 模板永久复用

**3. 项目上下文自动注入**
- 所有生成器默认读取当前项目的基础设定
- 生成内容自动贴合本小说世界观

#### 验收标准
- 生成器分类清晰，覆盖网文写作全场景
- 用户可创建、编辑、删除自己的生成器模板
- 生成结果自动匹配当前项目设定

---

### 模块5：残缺大纲导入、补全与合成系统

#### 功能点
1. **残缺大纲导入**
   - 支持粘贴碎片化剧情、零散设定、半截大纲
   - 系统自动提取有效信息，归类到对应项目素材

2. **智能补全生成**
   - 选中残缺大纲，可一键补全
   - AI自动填充缺失的分卷、章节、转折、结局
   - 支持选择补全风格（剧情流/爽文风/人设向）
   - 生成多版本可选

3. **多份大纲合成**
   - 支持选中2~5份残缺大纲/零散设定
   - AI自动梳理时间线、去重冲突、拼接逻辑
   - 生成一份完整总大纲

4. **全链路素材联动**
   - 补全/合成过程自动调用项目素材+公共素材
   - 保证设定统一
   - 生成结果自动拆分素材，归档到对应项目私有素材库

5. **结果一键投产**
   - 补全/合成后的完整大纲
   - 可一键发送到创作页，批量生成章节正文

#### 验收标准
- 粘贴半截零散大纲，可自动补全为结构完整的分卷大纲
- 2份以上残缺大纲可合成一份无逻辑冲突的完整大纲
- 新生成的设定自动存入项目素材库

---

### 模块6：爆文模板联网动态更新系统

#### 功能点
1. **联网定时更新**
   - 后端定时拉取公开网文资源
   - 按题材、功能分类更新爆文模板、爽点套路、经典桥段

2. **本地离线缓存**
   - 已下载的模板缓存到本地JSON
   - 断网状态可正常查看使用

3. **使用联动**
   - 模板支持一键导入为项目大纲
   - 一键发送到创作页作为提示词
   - 收藏到个人模板库

4. **分类体系**
   - 按题材筛选：玄幻/仙侠/都市/古言/现言
   - 按功能筛选：开局/反转/高潮/收尾

#### 验收标准
- 联网状态下模板库自动增量更新
- 断网状态可正常使用已缓存模板
- 模板可直接联动项目与创作页

## 4. 验收标准汇总

### 打包交付要求
1. 所有功能开发完成并测试通过后，执行前端编译 + Electron打包
2. 打包产物包含安装版EXE与便携版EXE
3. 所有新功能在桌面端无异常
4. 新增功能均有离线兜底方案
5. 保留原有一键启动、一键打包BAT脚本

### 兼容性要求
- 同时适配"浏览器模式"与"Electron桌面EXE模式"
- 向后兼容现有历史数据
- 不破坏原有素材、项目、配置
- UI风格与现有界面保持统一

---

## 5. 非功能需求

### 性能需求
- 页面切换流畅，无明显卡顿
- AI生成响应时间合理（取决于API速度）
- 大文件导入不阻塞UI

### 安全需求
- 本地数据不外传
- API密钥安全存储
- 用户创作内容隐私保护

### 兼容性需求
- Windows 10/11 系统支持
- 主流分辨率适配（1920x1080为主）
- 兼容原有功能和数据迁移
