# 灵墨小说工坊 PRD 产品需求文档

## 1. 产品概述

**灵墨小说工坊** 是一款面向网文作者的 AI 辅助小说创作桌面工具，基于 Electron + Vue3 + Express + 本地 JSON 存储架构，支持本地部署和离线使用，可打包为 Windows EXE 桌面软件。

### 核心價值
- 解决多份大纲素材混杂问题，实现项目化隔离管理
- 打通「素材库 → AI生成器 → 创作页」全链路，提升创作效率
- 融合多模块功能，消除页面割裂感
- 支持残缺大纲补全、多大纲合成等高级功能

### 目標用戶
- 网文小说作者（玄幻、仙侠、都市、同人等领域）
- 需要 AI 辅助创作、素材管理、大纲梳理的写作爱好者
- 追求本地部署、数据隐私的独立作者

## 2. 核心功能模塊

### 2.1 項目化管理體系

#### 功能說明
- **導入大綱自動建項**：每次執行「導入大綱」操作，系統自動以大綱名稱創建獨立「小說項目」
- **兩級素材體系**：
  - 全局公共素材庫：原內置古代常識、民俗神話等通用素材，所有項目均可調用
  - 項目私有素材庫：每個大綱/項目獨立存儲，僅包含該小說的人設、世界觀、場景、設定
- **智能拆分歸檔**：導入大綱後，自動識別並拆分「世界觀、人物、勢力、章節、場景」五類素材
- **項目導航**：左側新增「我的項目」樹形導航，點擊項目切換查看對應私有素材、大綱、章節

#### 數據結構改造
- 新增 `projects.json` 項目表
- 所有素材新增 `project_id` 字段，全局公共素材 `project_id = null`
- 原有自定義素材全部遷移為「全局公共素材」

### 2.2 AI創作頁與素材庫全鏈路打通

#### 功能說明
- **右側常駐素材抽屜**：AI創作頁右側新增可折疊素材面板，支持「全局素材/當前項目素材」切換、關鍵詞搜索、分類篩選
- **兩種素材調用方式**：
  - 一鍵插入正文：素材內容直接插入光標位置
  - 一鍵注入提示詞：素材內容自動追加到「創作提示/上下文」輸入框
- **自動聯動生成**：新增「素材聯動生成」開關，開啟後 AI 生成章節時自動讀取當前項目的核心人設、世界觀素材
- **生成結果回存素材**：AI 生成的人物、功法、場景內容，支持右鍵「保存為項目素材」

### 2.3 素材庫 / AI生成器 / 自定義素材 三模塊融合重構

#### 功能說明
- **頁面合併**：將原「素材庫與AI生成器」「自定義素材庫」兩個頁面，合併為統一的「素材與生成中心」單頁
- **統一導航結構**：
  - 左側：分類導航，包含「公共素材庫、項目素材庫、AI生成器、爆文模板」四大類
  - 中間：內容列表區
  - 右側：詳情/編輯/生成面板
- **雙向聯動能力**：
  - 查看任意素材時，右上角可「用該素材調用生成器」
  - AI生成器產出結果後，可一鍵「保存為公共素材」「保存到當前項目素材」
  - 自定義素材支持「套用生成器模板優化」
- **刪除投稿攻略模塊**：移除投稿攻略相關路由、菜單、組件與靜態資源

### 2.4 AI生成器精細化分類與自定義生成器

#### 功能說明
**生成器五級細分（共20+細分生成器）**：

| 類別 | 細分生成器 |
|------|-----------|
| 世界觀設定類 | 故事主線、勢力宗門、功法體系、世界規則、地理地圖 |
| 人物角色類 | 主角設定反派設計、配角群像、人物關係、角色成長線 |
| 劇情橋段類 | 劇情反轉、高潮場景、打鬥場面、情感互動、過渡銜接 |
| 文案包裝類 | 黃金開頭、書名生成、簡介文案、章節標題、對話潤色 |
| 輔助工具類 | 靈感火花、殘缺大綱補全、多大綱合成、正文擴寫/縮寫 |

**自定義生成器**：
- 支持用戶保存自己的 Prompt 模板
- 設置分類、參數、默認提示詞，永久複用

**項目上下文自動注入**：
- 所有生成器默認讀取當前項目的基礎設定
- 生成內容自動貼合本小說世界觀

### 2.5 殘缺大綱導入、補全與合成系統

#### 功能說明
- **殘缺大綱導入**：支持粘貼碎片化劇情、零散設定、半截大綱，系統自動提取有效信息，歸類到對應項目素材
- **智能補全生成**：
  - 選中殘缺大綱，可一鍵補全
  - AI 自動填充缺失的分卷、章節、轉折、結局
  - 支持選擇補全風格（劇情流/爽文風/人設向）
  - 生成多版本可選
- **多份大綱合成**：
  - 支持選中 2~5 份殘缺大綱/零散設定
  - AI 自動梳理時間線、去重衝突、拼接邏輯
  - 生成一份完整總大綱
- **全鏈路素材聯動**：補全/合成過程自動調用項目素材+公共素材
- **結果一鍵投產**：補全/合成後的完整大綱，可一鍵發送到創作頁批量生成章節正文

### 2.6 爆文模板聯網動態更新系統

#### 功能說明
- **聯網定時更新**：後端定時拉取公開網文資源，按題材、功能分類更新爆文模板、爽點套路、經典橋段
- **本地離線緩存**：已下載的模板緩存到本地 JSON，斷網狀態也可正常查看使用
- **使用聯動**：
  - 模板支持一鍵導入為項目大綱
  - 一鍵發送到創作頁作為提示詞
  - 收藏到個人模板庫
- **分類體系**：按題材（玄幻/仙俠/都市/古言/現言）+ 功能（開場/反轉/高潮/收尾）雙維度篩選

## 3. 核心頁面結構

| 頁面名稱 | 功能模塊 | 核心功能描述 |
|---------|---------|------------|
| 首頁/項目列表 | 項目管理 | 展示所有小說項目，創建/導入/刪除項目 |
| 項目詳情頁 | 大綱/章節/素材 | 查看項目大綱結構、章節列表、私有素材 |
| AI創作頁 | 章節編輯/生成 | 右側素材抽屜、一鍵插入/注入、聯動生成 |
| 素材與生成中心 | 素材/生成器/模板 | 三模塊融合的統一工作台 |
| 生成器配置頁 | 自定義模板 | 創建/編輯/刪除自定義生成器 |
| 設置頁 | 系統配置 | AI接口配置、主題設置、數據導出 |

## 4. 用戶核心流程

### 流程1：創建新項目並導入大綱
```
首頁 → 創建項目 → 導入大綱 → 自動拆分素材 → 進入項目詳情
```

### 流程2：AI輔助創作章節
```
項目詳情 → 選擇章節 → 開啟素材聯動 → 輸入創作提示 → AI生成 → 插入正文/保存素材
```

### 流程3：殘缺大綱補全
```
素材與生成中心 → 粘貼殘缺大綱 → 選擇補全風格 → AI補全 → 確認採用 → 保存為項目大綱
```

### 流程4：多大綱合成
```
素材與生成中心 → 選擇多份大綱 → 觸發合成 → AI梳理時間線 → 生成完整大綱 → 一鍵投產
```

## 5. UI設計規範

### 5.1 設計風格
- **視覺風格**：簡約現代中式設計，融合傳統文化元素
- **色彩體系**：
  - 主色：墨綠色 `#2D5A4A`（代表墨香文化）
  - 輔助色：宣紙米 `#F5F0E6`、硯台灰 `#4A4A4A`
  - 強調色：印章紅 `#C73E3A`
- **字體**：標題使用襯線字體（如思源宋體），正文使用無襯線字體（如思源黑體）
- **佈局**：左側樹形導航 + 右側內容區的經典後台佈局
- **圖標**：使用 Lucide Icons 圖標庫

### 5.2 組件規範
- 按鈕：圓角矩形，hover 有陰影過渡
- 卡片：帶輕微陰影和圓角，懸停邊框變色
- 輸入框：底部邊框樣式，聚焦時邊框變粗
- 抽屜：右側滑入，帶半透明遮罩層

## 6. 技術架構

### 6.1 技術棧
- **前端**：Vue3 + Vite + TypeScript + TailwindCSS
- **後端**：Node.js + Express + TypeScript
- **桌面端**：Electron 28.0.0
- **存儲**：本地 JSON 文件（無數據庫依賴）
- **AI 接口**：支持 OpenAI API 格式兼容的第三方大模型

### 6.2 適配要求
- 所有新功能同時適配「瀏覽器模式」與「Electron桌面EXE模式」
- 向後兼容現有歷史數據，不破壞原有素材、項目、配置
- UI規範與現有界面保持統一

## 7. 驗收標準

1. 連續導入2份不同大綱，生成2個獨立項目，私有素材互不干擾
2. 全局素材在所有項目內均可查看、調用
3. 原有歷史素材、配置全部正常保留
4. 創作頁內可完成素材搜索、調用、保存全流程，無需跳轉頁面
5. 無投稿攻略相關入口與殘留代碼
6. 一個頁面完成素材查閱、AI生成、自定義編輯全部操作
7. 生成器分類清晰，覆蓋網文寫作全場景
8. 粘貼半截零散大綱，可自動補全為結構完整的分卷大綱
9. 2份以上殘缺大綱可合成一份無邏輯衝突的完整大綱
10. 聯網狀態下模板庫自動增量更新，斷網狀態可正常使用已緩存模板
